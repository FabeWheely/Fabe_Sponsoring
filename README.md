# Fabe_Sponsoring
A repo for potential sponsors to contact me for my own website

## Content
- steckbrief
- contact form

## Kontaktformular starten

Python 3 wird benötigt. Starte den Server im Projektordner:

```powershell
python server.py
```

Öffne anschließend <http://127.0.0.1:8000>. Beim ersten Start werden die SQLite-Datenbank `contact.db` und die Tabelle aus `schema.sql` angelegt. Einsendungen erscheinen in einem Popup mit einer Erfolgs- oder Fehlermeldung. Die Nachricht wird nur bei erfolgreicher Speicherung als gesendet bestätigt.
